# MR0209: a default value on a `ref` parameter

A `ref` argument is a variable that the function changes, and a default value is a fixed value that belongs to no variable. When a call leaves the argument out, there would be nothing for the function to change, so Mora rejects the default.

Remove the default, so that every call passes a variable with `ref`, or remove `ref`, so that the parameter takes a value and can keep its default.

## Failing example

```mora
// error: MR0209
Bump(ref n: int = 1) {
    n += 1;
}
var count = 0;
Bump(ref count);
Console.WriteLine(count);
```

## Fixed example

```mora
// expect: 1
Bump(ref n: int) {
    n += 1;
}
var count = 0;
Bump(ref count);
Console.WriteLine(count);
```

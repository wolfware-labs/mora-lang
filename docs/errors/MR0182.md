# MR0182: a `let` local is reassigned

A `let` local is assigned exactly once, and this assignment would be a second one: the local has a value already, may have one from another path or from an earlier run of a loop that went on to the next run, or is assigned inside a lambda or a local function, which may run more than once. Code that reads a `let` relies on its value never changing.

Declare a local whose value changes with `var`, or assign the `let` once.

## Failing example

```mora
// error: MR0182
let count = 1;
count = count + 1;
Console.WriteLine(count);
```

## Fixed example

```mora
// expect: 2
var count = 1;
count = count + 1;
Console.WriteLine(count);
```

# MR0018: expressions, statements, types or patterns nested more than 256 levels deep

Each expression, statement, type or pattern inside another is one level of nesting, and so is each operator or call of a chain such as `a + b + c`, because it holds the chain before it. The compiler walks these levels recursively, so it accepts at most 256 of them. Code a person writes stays far below that; code generated by a tool can reach it, often as one long sum or one long chain of calls.

Split the expression: give a part of it a name with `let`, and use the name in the rest.

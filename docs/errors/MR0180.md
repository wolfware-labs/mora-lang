# MR0180: a local shadows a local or parameter of an enclosing scope

A local, a parameter of a lambda or local function, or a binding of a pattern takes the name of a local or parameter that is still in scope. From that point the name would mean the new one, and code that reads it could be reading a different value than its author expects, with no sign of the switch where it is used.

Rename the new local. A name may be used again once the earlier local is out of scope, as in two blocks side by side.

## Failing example

```mora
// error: MR0180
let count = 3;
if (count > 2) {
    let count = count * 2;
    Console.WriteLine(count);
}
```

## Fixed example

```mora
// expect: 6
let count = 3;
if (count > 2) {
    let doubled = count * 2;
    Console.WriteLine(doubled);
}
```

# MR0111: a modifier written twice

A declaration, a parameter or a lambda lists the same modifier twice, as in `public public X` or `mut mut Count`. Writing a modifier again says nothing new, so the repetition is most likely a slip, such as a modifier left behind after an edit.

Remove the repetition. The fix does so when both are written the same way. A `mut` repeated with another write scope, as in `mut mut(private) Count`, gets no fix: the two spellings allow writes from different places, and only the author knows which one is meant.

## Failing example

```mora
// error: MR0111
public struct Counter {
    public mut mut Count: int;
}
```

## Fixed example

```mora
// expect: 1
public struct Counter {
    public mut Count: int;
}

var counter = new Counter { Count = 0 };
counter.Count += 1;
Console.WriteLine(counter.Count);
```

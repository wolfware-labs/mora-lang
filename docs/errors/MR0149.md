# MR0149: a static member uses `this` or an instance member of its type

A `static` member belongs to the type, not to a value of it, so it runs with no value to read. Writing `this` in it, or naming an instance field, getter or method of the type by its bare name, which reads `this` implicitly, has nothing to refer to. The same holds for a local function or a lambda inside the static member. Mora rejects the use instead of reading a value that does not exist.

Take the value as a parameter and read its members through it, or remove `static` when the member works on a value of the type. The error offers no fix, because the right one depends on how the member is called.

## Failing example

```mora
// error: MR0149
public struct Counter {
    public Count: int;

    public static Doubled(): int => Count * 2;
}

Console.WriteLine(Counter.Doubled());
```

## Fixed example

```mora
// expect: 6
public struct Counter {
    public Count: int;

    public static Doubled(c: Counter): int => c.Count * 2;
}

let c = new Counter { Count = 3 };
Console.WriteLine(Counter.Doubled(c));
```

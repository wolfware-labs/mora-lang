# MR0186: the left side of an assignment, or the operand of `++` or `--`, that is not a place

An assignment, a compound assignment, `++` and `--` store a value in a place: a local, a parameter, a field of a place or an element. The left side here names something that holds no value of its own, such as a method or a local function, a getter without a setter, a constant or the result of a call, so there is nowhere to store the value. A field of a struct is part of the value that holds it, so a field of what a call or a getter gives is no place either: the change would go to a copy that nothing reads. `_` stands only on the left of a plain `=`, where it discards the value.

Assign to the field or local that holds the value, or call the method that changes it.

## Failing example

```mora
// error: MR0186
struct Counter {
    public mut Count: int;
    public Next(): int => Count + 1;
}

var c = new Counter { Count = 1 };
c.Next = 2;
Console.WriteLine(c.Count);
```

## Fixed example

```mora
// expect: 2
struct Counter {
    public mut Count: int;
    public Next(): int => Count + 1;
}

var c = new Counter { Count = 1 };
c.Count = c.Next();
Console.WriteLine(c.Count);
```

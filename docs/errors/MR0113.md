# MR0113: a modifier that does not apply to the declaration it is on

A modifier is written on a declaration it says nothing true about, as `const` on a getter in `const Limit: int => 10;`. A constant is a value fixed at compile time, while a getter computes its value on each read, so a reader would take the getter for a value it is not.

Remove the modifier. The fix removes `const` and keeps the getter. When a value fixed at compile time is meant, write a field with an initializer instead: `const Limit: int = 10;`.

## Failing example

```mora
// error: MR0113
public struct Counter {
    public const Limit: int => 10;
}
```

## Fixed example

```mora
// expect: 10
public struct Counter {
    public const Limit: int = 10;
}

Console.WriteLine(Counter.Limit);
```

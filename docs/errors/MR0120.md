# MR0120: an entry point whose return type is not `()`, `int`, `Result<(), E>` or `Result<int, E>`

What the entry point returns becomes the process's exit code, so it can only return nothing, an `int` exit code, or a `Result` of these, whose error makes the process exit with 1. A `string`, a `long` or a tuple has no exit code. For top-level statements, the first `return` with a value gives the generated `Main` its return type.

Return an `int`, converting the value if it is a number, or print the value and return nothing.

## Failing example

```mora
// error: MR0120
Main(): long {
    return 3;
}
```

## Fixed example

```mora
// expect: 3
// exit: 3
Main(): int {
    let total: long = 3;
    Console.WriteLine(total);
    return (int)total;
}
```

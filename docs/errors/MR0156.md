# MR0156: a type whose values would take more than 2^31 bytes

A value of any type takes at most 2^31 bytes, 2 GiB. A struct is stored inline wherever it is used, in a local, a field or a parameter, so a struct whose fields add up to more than that cannot be placed anywhere, and no stack has room for it. Each struct `S{i}` below holds two of the one before it, so `S29` would take 4 GiB.

Keep large data out of the struct: hold less inline, or keep the data in a collection or a class, which a struct stores as a pointer.

## Fixed example

```mora
// expect: 7
struct S0 { public A: long; }
struct S1 { public A: S0; public B: S0; }
let s = new S1 { A = new S0 { A = 7 }, B = new S0 { A = 8 } };
Console.WriteLine(s.A.A);
```

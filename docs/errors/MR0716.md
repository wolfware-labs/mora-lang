# MR0716: a host runs a generic `services` block

A host was given an instantiation of a generic `services` block as the composition it runs. Each composition a host runs is compiled as its own world, and that world must be a block the program declares, with a name that diagnostics, hover and `mora expand` can show. A generic block is meant to be inherited, not run.

Declare a block that inherits the instantiation, and give that block to the host. The new block is also where the app adds or overrides its own bindings.

## Failing example

```mora
// error: MR0716
public interface IGreeter {
    Greet(name: string): string;
}

public class PlainGreeter : IGreeter {
    public Greet(name: string): string => $"Hello, {name}";
}

services Greeting<TGreeter> where TGreeter : IGreeter {
    transient IGreeter = TGreeter;
}

let host = await ServiceHost.StartAsync<Greeting<PlainGreeter>>()?;
host.RunScoped((greeter: IGreeter) => Console.WriteLine(greeter.Greet("Ada")));
```

## Fixed example

```mora
// expect: Hello, Ada
public interface IGreeter {
    Greet(name: string): string;
}

public class PlainGreeter : IGreeter {
    public Greet(name: string): string => $"Hello, {name}";
}

services Greeting<TGreeter> where TGreeter : IGreeter {
    transient IGreeter = TGreeter;
}

services App : Greeting<PlainGreeter> {
}

let host = await ServiceHost.StartAsync<App>()?;
host.RunScoped((greeter: IGreeter) => Console.WriteLine(greeter.Greet("Ada")));
```

# MR0205: no function of the called name takes these arguments

The call does not match the function it names. With one declaration, an argument is missing for a parameter that has no default value, there is an argument that no parameter takes, or an argument is written with a marker its parameter's mode does not take, such as a missing `ref`. With overloads, none of them takes the arguments: for each one, some argument has no parameter, does not convert to its parameter's type, or has the wrong marker. Calling it anyway would leave a parameter without a value or put a value where it does not belong.

Give the call the arguments the function declares: one for every parameter without a default, of a type that converts to it, with `ref` exactly where the parameter is `ref`.

## Failing example

```mora
// error: MR0205
Area(width: int, height: int): int => width * height;
Console.WriteLine(Area(3));
```

## Fixed example

```mora
// expect: 12
Area(width: int, height: int): int => width * height;
Console.WriteLine(Area(3, 4));
```

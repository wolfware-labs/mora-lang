# MR0184: a function that returns a value can end without one

The function's return type is not `()`, but a path through its body reaches the end, or a `return` without a value, so a caller would receive no value. Every path must end in `return` with a value, a call of `panic`, `Unreachable` or `Todo`, or a loop that never ends.

Return a value on the path that has none, often in the `else` of an `if` that returns only in one branch.

## Failing example

```mora
// error: MR0184
Sign(n: int): int {
    if (n < 0) {
        return -1;
    }
}
Console.WriteLine(Sign(-5));
```

## Fixed example

```mora
// expect: -1
Sign(n: int): int {
    if (n < 0) {
        return -1;
    }
    return 1;
}
Console.WriteLine(Sign(-5));
```

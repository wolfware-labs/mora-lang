# MR0153: memberwise creation of a type that declares a constructor or is positional

`new T { ... }` without parentheses creates `T` memberwise, by naming its fields. A type that declares a constructor has turned memberwise creation off, so that every value goes through that constructor and the invariants it keeps. A positional struct's parameters declare its constructor, so it is not created memberwise either. Building such a value field by field would skip the constructor, so Mora rejects the expression.

Call a constructor instead: `new T(args)`, followed by `{ ... }` when the members it leaves writable should change afterwards. When the type declares a constructor visible there that takes no arguments, because it has no parameters or each has a default, and every name in the braces is a field visible there and declared `mut` without a write scope, the error offers a fix that adds `()`. A positional struct takes its positional parameters, `new User(1, "Ada")`.

## Failing example

```mora
// error: MR0153
public struct Counter {
    public mut Count: int;

    public Counter() {
        Count = 0;
    }
}

let c = new Counter { Count = 2 };
Console.WriteLine(c.Count);
```

## Fixed example

```mora
// expect: 2
public struct Counter {
    public mut Count: int;

    public Counter() {
        Count = 0;
    }
}

let c = new Counter() { Count = 2 };
Console.WriteLine(c.Count);
```

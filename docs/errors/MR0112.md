# MR0112: two modifiers that conflict: two visibilities, two parameter modes, or `mut` and `move` on a method

Some modifiers say different things about one property, so a declaration can carry only one of them. A declaration has one visibility (`private`, `file`, `internal` or `public`), a parameter has one mode (`in`, `ref` or `move`), and a method takes `this` one way (`mut` borrows it by `ref`, `move` takes it by `move`). Writing two of the same set, as in `public private Limit` or `ref move n: int`, leaves the compiler to guess which one is meant.

Keep the one that is meant. The fix removes the later modifier.

## Failing example

```mora
// error: MR0112
public struct Counter {
    public private Count: int;
}
```

## Fixed example

```mora
// expect: 2
public struct Counter {
    public Count: int;
}

let counter = new Counter { Count = 2 };
Console.WriteLine(counter.Count);
```

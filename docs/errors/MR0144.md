# MR0144: memberwise `new T { ... }` where a field without an initializer is not visible

`new T { ... }` must give a value to every field that has no initializer. When one of those fields is hidden from the code that creates the value, that code cannot name it, so it could never create a complete value. Mora rejects the expression instead of letting outside code bypass the type's own way of building it.

Create the value through what the type provides, such as a static factory, or let the type give the field an initializer or make the field visible to the code that creates it.

## Failing example

```mora
// error: MR0144
public struct Account {
    public Owner: string;
    private Balance: int;
}

let a = new Account { Owner = "ana" };
Console.WriteLine(a.Owner);
```

## Fixed example

```mora
// expect: ana
public struct Account {
    public Owner: string;
    private Balance: int;

    public static Open(owner: string): Account => new Account { Owner = owner, Balance = 0 };
}

let a = Account.Open("ana");
Console.WriteLine(a.Owner);
```

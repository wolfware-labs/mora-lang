# MR0185: an assignment used as a value

An assignment stores a value but gives none back, so it cannot be an argument, an operand, an initializer or a condition. Mora rejects the program here, because the line would be read as using the stored value while also changing a variable, and the two are easy to mix up. An assignment may only stand as a statement of its own. `x++` and `x--` are not assignments in this sense and can be used as values.

Write the assignment as a statement, then use the variable on the next line. When the assignment is the right-hand side of another one, as in `x = y = 5;`, the fix writes it as `y = 5; x = y;`.

## Failing example

```mora
// error: MR0185
var x = 0;
var y = 0;
x = y = 5;
Console.WriteLine(x + y);
```

## Fixed example

```mora
// expect: 10
var x = 0;
var y = 0;
y = 5;
x = y;
Console.WriteLine(x + y);
```

# MR0113: a modifier that does not apply to the declaration it is on

A modifier is written on a declaration it says nothing true about. `const` declares a constant, a value fixed at compile time, and only a field with an initializer is one. On anything else it misleads: a getter computes its value on each read, as in `const Limit: int => 10;`; a function, a method, a constructor or an indexer runs as code; a type declares a type; and a parameter takes its value from each call.

Remove the modifier. The fix removes `const` and keeps the declaration. When a value fixed at compile time is meant, write a field with an initializer instead: `const Limit: int = 10;`.

## Failing example

```mora
// error: MR0113
public struct Counter {
    public const Limit: int => 10;
}
```

## Fixed example

```mora
// expect: 10
public struct Counter {
    public const Limit: int = 10;
}

Console.WriteLine(Counter.Limit);
```

# MR0181: a local used before it is definitely assigned

The local is declared without a value, and some path reaches this read without assigning it: an `if` without `else` that assigns it in one branch, or a loop that may not run. Reading it there would read memory that holds no value of its type. A lambda or a local function sees only what is assigned where it is declared.

Assign the local on every path before the read, or give it a value where it is declared.

## Failing example

```mora
// error: MR0181
let ready = true;
var total: int;
if (ready) {
    total = 3;
}
Console.WriteLine(total);
```

## Fixed example

```mora
// expect: 3
let ready = true;
var total: int;
if (ready) {
    total = 3;
} else {
    total = 0;
}
Console.WriteLine(total);
```

# MR0204: an operator is not defined for the types of its operands

An operator is applied to values it does not work on. A `long` and a `ulong` have no common type that holds every value of both, so adding them could give a wrong answer for large or negative values; the same holds for a `long` and a `float`. Other cases are `&` or `<<` on floating-point numbers, `-` on a `ulong`, `!` on a number, `+` between a `string` and a number, and a cast `(T)x` that is not from one numeric type to another.

Say which type the operation works in with an explicit cast on one operand, as in `(long)size + offset`. Join text with interpolation, `$"{name}{count}"`, and compare a number explicitly, `count == 0`, where a `bool` is needed.

## Failing example

```mora
// error: MR0204
let offset: long = -5;
let size: ulong = 10;
let end = size + offset;
Console.WriteLine(end);
```

## Fixed example

```mora
// expect: 5
let offset: long = -5;
let size: ulong = 10;
let end = (long)size + offset;
Console.WriteLine(end);
```

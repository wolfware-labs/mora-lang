# MR0203: mismatched types: a value of type `S` where `T` is expected and `T` does not implement `IFrom<S>`

A value is used where another type is expected: the initializer of a local with a declared type, a value assigned to a variable or a field, a value returned from a function, or a condition, which must be a `bool`. Mora converts a value implicitly only when nothing can be lost: an `int` widens to a `long`, but a `long` does not narrow to an `int`, because a large value would silently wrap. Nothing converts implicitly to or from `bool`, between `char` and integers, or to `string`.

Give the place the value's type, or convert the value yourself. An explicit cast `(int)x` converts between numeric types and truncates when the value does not fit; interpolation, `$"{x}"`, formats any value as text; a comparison, `x != 0`, turns a number into a `bool`.

## Failing example

```mora
// error: MR0203
let total: long = 5_000_000_000;
let shown: int = total;
Console.WriteLine(shown);
```

## Fixed example

```mora
// expect: 5000000000
let total: long = 5_000_000_000;
let shown: long = total;
Console.WriteLine(shown);
```

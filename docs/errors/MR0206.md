# MR0206: a call for which more than one overload fits equally well

Two or more overloads take the arguments of the call, and none fits them better than all the others: one converts an argument more closely, another a different one. Picking either silently could call a function the author did not mean, and adding an overload later could change which one runs.

Convert an argument explicitly so that one overload fits best, for example with a suffix such as `3L` or a cast `(long)x`, or name the overloads differently.

## Failing example

```mora
// error: MR0206
Scale(x: int, factor: long): long => x * factor;
Scale(x: long, factor: int): long => x * factor;
Console.WriteLine(Scale(2, 3));
```

## Fixed example

```mora
// expect: 6
Scale(x: int, factor: long): long => x * factor;
Scale(x: long, factor: int): long => x * factor;
Console.WriteLine(Scale(2, 3L));
```

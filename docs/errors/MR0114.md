# MR0114: a constant without a value

A `const` field, in a type or in a namespace, is declared without a value, as in `const Limit: int;`. A constant is a value fixed at compile time, so the value is part of its declaration: there is nowhere else to give it, and no reader could tell what the constant holds.

Write the value after the type: `const Limit: int = 10;`. There is no fix, because only the author knows the value. When the value is meant to be given per instance, the member is a field without `const`.

## Failing example

```mora
// error: MR0114
public struct Counter {
    public const Limit: int;
}
```

## Fixed example

```mora
// expect: 10
public struct Counter {
    public const Limit: int = 10;
}

Console.WriteLine(Counter.Limit);
```

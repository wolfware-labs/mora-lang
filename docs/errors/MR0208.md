# MR0208: a call of a value that is not a function

The expression before the parentheses is a value, such as a number, a string or a struct, and its type is not a function type, so there is nothing to call. This usually means a stray pair of parentheses, or a value that has the name of a function the author meant.

Remove the parentheses to use the value, or call the function the value was confused with.

## Failing example

```mora
// error: MR0208
let total = 3;
Console.WriteLine(total());
```

## Fixed example

```mora
// expect: 3
let total = 3;
Console.WriteLine(total);
```

# MR0143: memberwise creation does not assign a field that has no initializer

`new T { ... }` creates a struct from the fields it lists, and `new T()` on a struct that declares no constructor lists none. A field that has no initializer and is not listed would have no value, so Mora rejects the expression instead of leaving the field unset.

Assign the field in the `new` expression, or give the field an initializer in the struct. A field that has an initializer may be left out.

## Failing example

```mora
// error: MR0143
public struct Point {
    public X: int;
    public Y: int;
}

let p = new Point { X = 3 };
Console.WriteLine(p.X);
```

## Fixed example

```mora
// expect: 7
public struct Point {
    public X: int;
    public Y: int;
}

let p = new Point { X = 3, Y = 4 };
Console.WriteLine(p.X + p.Y);
```

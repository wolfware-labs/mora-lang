# MR0152: the initializer of an instance field uses `this` or an instance member of its type

The initializer of an instance field runs when a value is created, for each field that `new T { ... }` leaves out, before the value exists. It has no `this`, so writing `this` in it, or naming an instance field, getter or method of the type by its bare name, which reads `this` implicitly, has nothing to refer to. The same holds for a lambda or a local function inside the initializer. Constants and `static` members belong to the type, so an initializer may use them.

Give the field a value that does not depend on the other fields and assign it where the value is created, or compute it in a getter. The error offers no fix, because the right one depends on what the field means.

## Failing example

```mora
// error: MR0152
public struct Size {
    public Width: int = 1;
    public Height: int = Width;
}

Console.WriteLine(new Size().Height);
```

## Fixed example

```mora
// expect: 1
public struct Size {
    public Width: int = 1;
    public Height: int => Width;
}

Console.WriteLine(new Size().Height);
```

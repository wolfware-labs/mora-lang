# MR0148: memberwise `new T { ... }` assigns a field twice

`new T { ... }` gives each field its value once. When a field appears twice, only one of the values could end up in it, and the other would be computed and lost, so Mora rejects the expression instead of picking one.

Keep one assignment of the field. The fix removes the repeated one, which keeps the value written first.

## Failing example

```mora
// error: MR0148
public struct Point {
    public X: int;
    public Y: int;
}

let p = new Point { X = 3, Y = 4, X = 5 };
Console.WriteLine(p.X);
```

## Fixed example

```mora
// expect: 7
public struct Point {
    public X: int;
    public Y: int;
}

let p = new Point { X = 3, Y = 4 };
Console.WriteLine(p.X + p.Y);
```

# MR0147: memberwise `new T { ... }` assigns a name that is not an instance field of `T`

`new T { ... }` creates a struct by giving a value to each field that every value of `T` holds. A name in it that is not such a field would assign nothing: a misspelled field, a getter, which computes its value, or a `static` field or a constant, which belong to the type rather than to one value. Mora rejects the expression instead of dropping the value.

Write the name of an instance field of `T`. When the name is close to a field that the expression does not assign yet, the error suggests that field. Set a `static mut` field with an assignment of its own, and leave getters and constants out.

## Failing example

```mora
// error: MR0147
public struct Point {
    public X: int;
    public Y: int = 0;
}

let p = new Point { X = 3, Yy = 4 };
Console.WriteLine(p.X);
```

## Fixed example

```mora
// expect: 7
public struct Point {
    public X: int;
    public Y: int = 0;
}

let p = new Point { X = 3, Y = 4 };
Console.WriteLine(p.X + p.Y);
```

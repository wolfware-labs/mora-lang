# MR0462: a constant whose value depends on itself

To compute a constant, the compiler first computes every constant it reads. When a constant reads itself, directly or through other constants or field initializers, that chain never ends, so the constant has no value. The note lists the cycle in the order each one reads the next.

Break the cycle: give one of the constants a value that does not read the others.

## Failing example

```mora
// error: MR0462
const A: int = B + 1;
const B: int = A + 1;
Console.WriteLine(A);
```

## Fixed example

```mora
// expect: 2
const A: int = B + 1;
const B: int = 1;
Console.WriteLine(A);
```

# MR0115: a member that an interface, an extension or a union cannot have

An interface says what a type provides, and an extension adds methods and getters to a type it does not declare. Neither holds a value of its own or frees one, so an interface has no fields and no destructors, and an extension adds no fields, destructors or static members. An interface's static members are `static abstract`, which each implementing type gives, so a static method or getter without `abstract` is an error there too, and neither an interface nor an extension holds a nested type, which belongs in the namespace. An extension adds methods and getters only: an indexer or an associated type in it is an error as well. In an interface, a member written with a value, as `Limit: int = 10;`, is a field, and `static Count: int = 0;` is a static field; in an extension, so are `Limit: int;` and `static Count: int = 0;`, and a static method, a static getter or an operator, which is a static method, is a static member. Nothing would store such a field: the types that implement the interface, or the type the extension adds to, have no room for it. A union holds exactly one of its cases, and its data lives in them, so it has no instance fields either: `Color: string = "black";` after its cases, with a value or without, has no case to live in. Its constants and static fields stay its own.

Declare the member where it belongs. A value each implementing type gives is a getter in the interface, as `Limit: int;`, which may have a default, as `Limit: int => 10;`, or for a value of the type rather than of an instance, a static abstract getter, `static abstract Limit: int;`. A value every implementation shares is a constant in the namespace, next to the interface or the extension, as `const Limit: int = 10;`. A static member that each implementing type gives is `static abstract`, with a body for a default, as `static abstract Zero: int => 0;`; one that every implementation shares is a function in the namespace. A type goes in the namespace, and an associated type in an interface. A field, a destructor, an indexer or a static member of the type itself is declared in the type, and an extension can add a method that takes the index instead of an indexer. A value a union carries goes in each case that has it, or the union is wrapped in a struct with the value beside it: `struct Drawn { Shape: Shape; Color: string; }`. There is no fix, because only the author knows which of these is meant.

## Failing example

```mora
// error: MR0115
public interface IBuffer {
    Limit: int = 10;
}
```

```mora
// error: MR0115
public struct Point {
    public X: int;
}

extension(p: Point) {
    public static Origin(): Point => new Point { X = 0 };
}
```

```mora
// error: MR0115
public union Shape {
    Circle(Radius: double),
    Square(Side: double);

    Color: string = "black";
}
```

## Fixed example

```mora
// expect: 10
public const Limit: int = 10;

public interface IBuffer {
    Size: int;
}

Console.WriteLine(Limit);
```

```mora
// expect: 0
public struct Point {
    public X: int;

    public static Origin(): Point => new Point { X = 0 };
}

Console.WriteLine(Point.Origin().X);
```

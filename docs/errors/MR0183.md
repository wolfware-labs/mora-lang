# MR0183: `break` or `continue` outside a loop

`break` and `continue` act on the innermost `while`, `do`, `for` or `foreach` around them, and there is none here. A lambda or a local function does not see the loops around it, so a `break` in one has no loop to leave either.

Move the statement into the loop, or end the code another way, such as with `return`.

## Failing example

```mora
// error: MR0183
let done = true;
if (done) {
    break;
}
Console.WriteLine("after");
```

## Fixed example

```mora
// expect: after
let done = true;
while (!done) {
    break;
}
Console.WriteLine("after");
```

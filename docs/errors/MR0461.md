# MR0461: a constant evaluation that fails

A constant is computed when the program is compiled. An operation that would panic at run time, such as an integer overflow or a division by zero, has no value to give the constant, so Mora reports it as an error in every build profile. The message shows the operation with the values it was given.

Use a type wide enough for the result, or change the operands so the operation has a value.

## Failing example

```mora
// error: MR0461
const Big: int = 2_000_000_000;
const Twice: int = Big * 2;
Console.WriteLine(Twice);
```

## Fixed example

```mora
// expect: 4000000000
const Big: long = 2_000_000_000;
const Twice: long = Big * 2;
Console.WriteLine(Twice);
```

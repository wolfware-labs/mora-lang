# MR0460: a constant expression that cannot be evaluated at compile time

A constant gets its value when the program is compiled, so its expression can use only what the compiler can run on its own: literals, operators, casts, other constants and the creation of structs and tuples. A call of a function, a local variable or `this` needs the program to be running, so Mora rejects it in a constant. The same holds for a parameter's default value, and for a field's initializer when a struct created at compile time leaves that field out.

Write the value as a constant expression. A value that can only be computed when the program runs can be a `static lazy` instead.

## Failing example

```mora
// error: MR0460
Zero(): int => 0;
const A: int = Zero();
Console.WriteLine(A);
```

## Fixed example

```mora
// expect: 0
const A: int = 0;
Console.WriteLine(A);
```

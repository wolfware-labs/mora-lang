# MR0207: a named argument that names no parameter, names one twice, or comes before a positional one

Named arguments come after the positional ones, and each names a parameter of the function once. This call has a positional argument after a named one, gives one name twice, names a parameter the function does not have, or names a parameter that a positional argument already gives. Any of these leaves it unclear which parameter an argument is for.

Put the positional arguments first, give each name once, and use the names the function's parameters have.

## Failing example

```mora
// error: MR0207
Greet(name: string, greeting: string = "Hello"): string => $"{greeting}, {name}!";
Console.WriteLine(Greet(greeting: "Hi", "Ada"));
```

## Fixed example

```mora
// expect: Hi, Ada!
Greet(name: string, greeting: string = "Hello"): string => $"{greeting}, {name}!";
Console.WriteLine(Greet("Ada", greeting: "Hi"));
```
